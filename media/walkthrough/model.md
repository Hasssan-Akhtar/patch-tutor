## Pick a model

Patch Tutor needs a language model to explain and quiz. It has no backend of its own.

- **VS Code models** (default): GitHub Copilot, or any model another extension adds to VS Code. No key needed.
- **Anthropic**: Claude models with your own API key.
- **OpenAI-compatible**: OpenAI, OpenRouter, Groq, LM Studio and others.
- **Ollama**: a local model. Nothing leaves your machine.

Keys are kept in VS Code's secret storage and are sent only to the provider you choose.
